Developer Execution Summary – KYC
Goal: Keep onboarding under 2–3 minutes.
Build Flow:
	•	Account creation (OTP + email)
	•	ID scan + liveness
	•	Backend sanctions + PEP screening
	•	Risk score calculation
	•	Unlock dashboard + offers
Critical Engineering Requirements:
	•	Encrypted storage (AES-256 at rest)
	•	TLS 1.2+ in transit
	•	Consent logs timestamped
	•	Audit trail for screenings
	•	Role-based access control
Do NOT build:
	•	Full AML transaction monitoring engine
	•	Deep forensic review system
	•	Continuous behavioral AML monitoring

Developer / Founder Execution Summary – Licensing
For MVP:
	•	Register mainland LLC with activity: Credit Brokerage
	•	Draft AML policy
	•	Appoint MLRO
	•	Avoid touching funds
	•	Do NOT intermediate repayments
Engineering rule: System must never hold or route customer funds.
Revenue should be:
	•	Referral fee
	•	Success commission from bank
	•	Platform fee (not transaction custody)

Developer Execution Summary – Open Banking
Rules:
	•	Always obtain explicit consent before connecting accounts
	•	Use provider SDK securely
	•	Store only what is necessary (derived metrics > raw transactions)
	•	Build data deletion endpoint
	•	Never initiate payments
Architecture Tip: Store:
	•	Income average
	•	DTI ratio
	•	Cashflow stability score
Avoid storing:
	•	Full transaction histories
	•	Merchant-level raw data long term
