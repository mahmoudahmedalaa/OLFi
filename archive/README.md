# OLFi Archive

This folder is for preserved historical/local material that should not participate in active builds.

Rules:

- Read-only by default.
- Do not import code from here into `app/`, `web/`, `admin/`, or `supabase/` without an explicit decision.
- Prefer moving uncertain material here over deleting it.
- If an archived item becomes useful, document why it is being promoted back into a canonical surface.

- `archive/pre-cleanup-20260511` preserves the exact repo working tree before the May 2026 stabilization pass.
